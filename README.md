# Data Capture Systems (DCS) Website

A modern marketing and product website for Data Capture Systems GmbH — counter-drone, cybersecurity, and security operations.

## Tech Stack

- **Framework:** [Next.js]
- **Styling:** [Tailwind CSS]
- **Language:** TypeScript

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install & Run

# Install dependencies
npm install

# Run development server
npm run dev

# View it on the browser
https://datacaptture.vercel.app/
